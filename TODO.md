# 🏛️ Mnemotheca — TODO & Roadmap

Mnemotheca is a privacy-first desktop gallery for personal media libraries. The current focus is on local browsing, folder management, and polished browsing workflows without cloud dependency.

## ✅ Hecho en el estado actual

- [x] Local-first media library for photos, videos and audio.
- [x] Folder management: add, remove and update stored folders.
- [x] Automatic detection of system folders such as Desktop, Downloads, Documents, Pictures, Music and Videos.
- [x] Browse media by folder with a gallery view and filters by type, date and extension.
- [x] Date extraction from EXIF metadata for image files.
- [x] Local media scanning with progress reporting and file-type detection.
- [x] Purple-themed interface with dark/light mode support.
- [x] Update pipeline via electron-updater for packaged versions.

## 🔧 Mejoras pendientes y en curso

- [ ] Advanced filters by resolution, aspect ratio, duration, bitrate and file size.
- [ ] Metadata panel for active media files (EXIF/ID3 details).
- [ ] Batch operations: multi-select, bulk move/export or tagging.
- [ ] More polished app branding: icons, installer assets and final visual refinements.
- [ ] Improve onboarding and empty states for first-time users.
